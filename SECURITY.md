# Security

Debo will hold very personal data, so security reports matter a lot to us.

## Reporting a problem

Please do not open a public issue.

Use GitHub's private reporting: on this repo, open the **Security** tab and choose **Report a vulnerability**.

Include what you found, how to reproduce it, and what an attacker could do with it. Use test data only. Do not access anyone else's data.

## What to expect

This is a one-person project today. There is no bug bounty and no guaranteed response time. Reports will be read and handled as quickly as one person can.

## Scope

Today only the landing page in `apps/web` is live code. The rest of the repo is documentation.
